# ReplayChess directory playbook — 2026-09-13

One row per directory, derived from the EasyInterview sweep (`../easyinterview/marketing/directory-playbook-2026-09-09.csv`,
407 hosts attempted, 57 live) filtered for what fits a consumer, open-source chess game, plus chess/open-source/store
targets EasyInterview never needed. **278 hosts.** The CSV beside this file is the working tracker — update
`status`, `listing_url`, `notes`, `date` there as each one goes live. The `ei_*` columns are what happened when the
same host was tried for EasyInterview: `live`/`submitted` means the flow works; `blocked` says why it didn't.

Dropped on purpose: B2B review platforms (G2, Capterra, GetApp, TrustRadius, SoftwareSuggest, Techjockey…), HR/recruiting
verticals, AI-tool directories, India business listings, paid-only and dead sites.

Priority reads like a chess annotation: `!!` do first · `!` strong · `!?` worth a try · `?!` only if bored (EasyInterview
was blocked there, or it needs payment/phone). Time: Bullet < 5 min · Blitz < 15 · Rapid < 1 h · Classical needs prep.

## The recipe (same as EasyInterview's, adapted)

1. **Identity.** One dedicated Google account for directory sign-ins (never the personal one — Toolify silently bound
   EasyInterview's personal account). Work-email fields = `hello@playchess.tech`. Contact = Rohit Pandit, Founder.
2. **Copy.** `directory-submission-kit.md` — rotate the tagline and the three features you emphasise between
   directories in the same tier; never paste one long description twice in a tier.
   URL: `https://www.playchess.tech/?utm_source=<host>&utm_medium=directory&utm_campaign=listings`.
3. **Assets.** Everything is on `/press`: logo `/chess-logo-bnw.png`, icon `/icons/icon-512x512.png`, social
   `/og-image.jpg` (1200×630), trailer `/ReplayChessTrailer.mp4`. Homepage screenshot 1440×900: capture once, keep in
   the scratchpad.
4. **Never pay, never tick paid add-ons.** Badge-for-dofollow is always taken: append to `DIRECTORY_BADGES` /
   `DIRECTORY_TEXT_LINKS` in `apps/web/app/components/DirectoryBadges.tsx`, deploy, wait for Vercel, then press the
   directory's Verify. Never remove a badge without checking the listing first.
5. **Verify after listing.** `curl -sL <listing> | grep -o '<a [^>]*playchess[^>]*>'` and record `rel` in the CSV.
6. **Dedupe first.** Search the directory for "ReplayChess" and "playchess" before creating anything.
