## Core facts (single source of truth — keep these consistent everywhere)

- **Product:** ReplayChess
- **Tagline:** Play the critical position from famous chess games
- **Category:** Games / Chess · Education / Learning · Open Source · Web app (PWA)
- **Who it's for:** Club and online chess players (roughly 800–2000 rating) who watch Agadmator, GothamChess and
  chess history videos and want to *play* the positions instead of just watching them. Also chess coaches looking
  for training positions, and developers interested in an open-source real-time multiplayer app.
- **What it does:** Pick a legendary game, start from its critical position, and try to find the moves the
  grandmaster found — against a friend (private link), a matched opponent (ELO queue), or Stockfish in the browser.
  Post-game analysis shows your match rate and the exact move where you left the legend's line. An openings
  encyclopedia of 3,600+ ECO-coded positions to play from. Tournaments. Installs as a PWA.
- **Numbers you may quote:** 50+ chess legends · 3,600+ ECO-coded openings · 4 Stockfish levels (Easy → Expert,
  ~2200) · MIT-licensed, source on GitHub. Do **not** quote user or game counts.
- **Competitors / "alternative to":** Chess.com, Lichess, Chessable, Chess Tempo, Aimchess, Chessify, chess24 (defunct).
  Open-source alternative to: Chess.com. Never claim to be an alternative to a chess *engine* (Stockfish is what we run).
- **Pricing:** Free to play. Player plan $4.99/month or $50/year unlocks the full legend and opening catalogue.
  If a form forces "starting price": `$4.99/month` or "Freemium".
- **Tech (for dev directories):** Next.js 15, React 19 (React Compiler), TypeScript, Tailwind v4, Prisma + Postgres (Neon),
  Clerk, Socket.IO, Stockfish WASM, PWA. Deployed on Vercel; websocket server on EC2.
- **Repo:** `https://github.com/replay-chess/chess-battle-turbo` (MIT)
- **Logo:** `https://www.playchess.tech/chess-logo-bnw.png` · icon 512: `https://www.playchess.tech/icons/icon-512x512.png`
- **Social image 1200×630:** `https://www.playchess.tech/og-image.jpg`
- **Trailer:** `https://www.playchess.tech/ReplayChessTrailer.mp4`
- **Socials / contact:** x.com/anaestheticdev · hello@playchess.tech · founder Rohit Pandit
- **Not:** an AI tool, a chess engine, a SaaS for businesses, a coaching service, a mobile-store app (yet).
- **Do not claim:** ratings improvement figures, user counts, named customers, "used by titled players".

**Use for:** GitHub awesome lists, Next.js Showcase, Vercel Templates, Dev Hunt, LibHunt, Open Hub, SourceForge,
Made with React, StackShare, Dev.to, Hashnode

> ReplayChess is an open-source (MIT) chess platform where you replay famous games from their critical position
> against real opponents or Stockfish. Built with Next.js 15 and React 19 with the React Compiler, TypeScript,
> Tailwind v4, Prisma on Postgres, Clerk auth, Socket.IO for real-time matchmaking and play, and Stockfish compiled to
> WASM running in the browser. Ships as an installable PWA. The web app runs on Vercel; the websocket server on EC2.
>
> Interesting parts of the codebase: ELO matchmaking over Socket.IO, browser-side engine analysis with divergence
> detection against the historical line, an ECO openings importer, and a k6 performance suite for the game loop.
>
> Repo: github.com/replay-chess/chess-battle-turbo · Live: playchess.tech
